Elementos de bloco

ocupam toda largura disponivel, exemplo: <div><p><h1>, <select>, <article>

Elementos de linha

Ocupao apenas o espaço necessário na linha, exemplo: <a><span><strong>, <em>, <img>

Regras importantes

Elementos de linha não devem conter elementos de bloco

Sectioning Content

Organizar grandes áreas do documento

<section>: agrupa conteúdos que partilham do mesmo assunto/idéia.

<article>: conteúdo independente e completo por si só (faz sentido sozinho).

< aside>: serve para guardar um conteúdo secundário/lateral (links relacionados, anúncios, biografia e etc).

<nav> agrupar links de navegação

heading content

h1,h2,h3,h4,h5,h6,: adicionar titulos e subtitulos

elementos que marcam textos ou partes de textos

<span>: Um bloco genérico, não muda nada sozinho, porém pode aplicar CSS ou chamar funções/comportamento com javascript

<a>: criar um link para direcionar o usuário para outra pagina, utilizando o atributo href. Exemplo: clique para conhecer o elden-ring

<strong≷: serve para deixar uma parte do texto em

<em≷ serve para deixar uma parte do texto em

<mark≷: serve para adiconar um marcador em uma parte do texto

embedded content

Ultilizado para inserir um conteudo externo

<img>: importar imagem, desenho,foto (não precisa de tag de fechamneto)

<video≷ adiconar algum video(pode mostrar botões como o play).

<canva≷ criar uma tela branco que podera ser pelo javascript

<svg≷: desenhar graficos baseados em vetores

<iframe≷colocar outra pagina inteira dentro do seu website(muito usado para adicionar mapas e videos)
